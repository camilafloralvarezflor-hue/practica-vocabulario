# Práctica de vocabulario

Juego para practicar el vocabulario de **English File Upper-Intermediate (4th edition)**: las 12 unidades del Vocabulary Bank (SB p. 152–163) y los phrasal verbs del libro. Son 598 palabras en total.

**Jugar:** https://camilafloralvarezflor-hue.github.io/practica-vocabulario/

- Leés la definición en inglés y escribís la palabra en los cuadraditos.
- Tenés botones de pista (traducción y primera letra), mostrar respuesta y siguiente.
- Podés elegir uno o varios temas y armar rondas de 10, 20, 30 o 50 palabras.
- Hay un modo para repasar las que fallaste.
- El progreso se guarda en el navegador.

Es un solo archivo (`index.html`), sin dependencias: también funciona descargándolo y abriéndolo con doble clic.
